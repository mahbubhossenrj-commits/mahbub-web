# Tawsif Mahbub — Personal Website

A responsive bilingual (English/Bangla) personal brand, portfolio and blog website.

## Files
- `index.html` — page content and sections
- `style.css` — responsive colorful design
- `script.js` — mobile navigation, language switcher and dynamic year

## Preview locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click it in a browser.

## Before publishing
1. In `index.html`, replace `hello@example.com` with your real email address.
2. Add your real YouTube, GitHub, Facebook and other social profile links when ready.
3. Replace the sample project/blog descriptions with your published work as it becomes available.
4. You can add your own photo later; the hero currently uses a designed monogram illustration.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `tawsif-mahbub-portfolio`).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for the Pages deployment to finish. GitHub will show the published URL in Settings → Pages.

GitHub Pages hosts static HTML, CSS and JavaScript files. No backend or database is included in this starter website.
