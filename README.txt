HOW TO PREVIEW
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server, or double-click index.html.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository (for a user site, name it username.github.io).
2. Upload all files and the assets folder, keeping the folder structure unchanged.
3. Open repository Settings > Pages.
4. Choose Deploy from a branch, select main and /root, then Save.
